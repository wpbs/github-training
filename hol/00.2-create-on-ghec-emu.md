# Create your lab repository on GitHub Enterprise Cloud at github.com (EMU)

Sign in to `github.com` with your managed user account and create an empty repository under your enterprise's organization (e.g. `actions-fundamentals-{yourname}`). Do not initialize it with a README, `.gitignore`, or license.

1. On the page of your new, empty repository, click the big green <kbd>Code</kbd> button and copy the HTTPS clone URL. This is your **target** URL: `<TARGET-REPO-CLONE-URL>`.
2. Open the template repository your trainer pointed you to, click the big green <kbd>Code</kbd> button and copy the HTTPS clone URL. This is your **source** URL: `<SOURCE-TEMPLATE-CLONE-URL>`.
3. Use the source URL to create a local copy, then change the remote to your target repository and push:

   ```bash
   git clone <SOURCE-TEMPLATE-CLONE-URL> ActionsFundamentals
   cd ActionsFundamentals
   git remote set-url origin <TARGET-REPO-CLONE-URL>
   git push --set-upstream origin main
   ```

   Replace `<SOURCE-TEMPLATE-CLONE-URL>` and `<TARGET-REPO-CLONE-URL>` with the URLs you copied.

4. Note the complete repository location: `github.com/<owner>/<repository>`. You will use this as your lab repository throughout the exercises.
