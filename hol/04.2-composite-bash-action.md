# Create a composite action using bash

Create the action in a new folder `hello-world-composite-bash-action` in [your lab repository](../).

1. Create a new file [`hello-world-composite-bash-action/action.yml`](/../../new/main?filename=hello-world-composite-bash-action%2Faction.yml)

2. Add content to the `action.yml` file following the
  [instructions](https://docs.github.com/en/actions/tutorials/create-actions/create-a-composite-action). Have the action run as `composite`, pass
  in the parameter `who-to-greet` with the default value `World`, and return an output `time` with the current time.

<details>
  <summary>Solution</summary>

```YAML
name: Hello World (bash)
description: Greet someone and record the time
inputs:
  who-to-greet:
    description: Who to greet
    required: true
    default: World
outputs:
  time:
    description: The time we greeted you
    value: ${{ steps.time.outputs.time }}
runs:
  using: composite
  steps:
    - name: Set Greeting
      shell: bash
      run: echo "Hello $INPUT_WHO_TO_GREET."
      env:
        INPUT_WHO_TO_GREET: ${{ inputs.who-to-greet }}

    - name: Get the time
      id: time
      shell: bash
      run: echo "time=$(date)" >> "$GITHUB_OUTPUT"

    - name: Add the action folder to the PATH
      shell: bash
      run: echo "$GITHUB_ACTION_PATH" >> "$GITHUB_PATH"

    - name: Run goodbye.sh
      shell: bash
      run: goodbye.sh
```

</details>

3. Create the file [`goodbye.sh`](/../../new/main?filename=hello-world-composite-bash-action%2Fgoodbye.sh) in the folder. It is a simple script that writes a message to the console.

<details>
  <summary>Solution</summary>

```bash
#!/bin/bash

echo "Goodbye"
```

</details>

4. Set the executable bit when you commit it. The GitHub web editor can't do this, so commit `goodbye.sh` from a local clone (or a Codespace).

<details>
  <summary>Solution</summary>

```bash
git add --chmod=+x hello-world-composite-bash-action/goodbye.sh
git commit -m "Make goodbye.sh executable [skip ci]"
git push
```

If you can't use git locally, change the last step of the action to `run: bash "$GITHUB_ACTION_PATH/goodbye.sh"`, which doesn't need the executable bit.

</details>

Commit your files (`[skip ci]` to not run a build, yet) and continue with [Testing the action](04-My-first-action.md#testing-the-action).
