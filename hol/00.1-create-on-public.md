# Create your lab repository on GitHub.com

1. Open the template repository your trainer pointed you to and click <kbd>Use this template</kbd>.

   <img width="400" alt="Use this template" src="https://user-images.githubusercontent.com/5276337/190895393-6fa0fad9-e05c-4fea-8126-a291b087d663.png">

2. Select your GitHub user or organization as the owner and choose a repository name. Leave the repository public to have unlimited Actions minutes.

   <img width="400" alt="Choose the repository owner and name" src="https://user-images.githubusercontent.com/5276337/190895398-751a1ec9-c1cf-497f-beb7-a6b53d4d911e.png">

3. Create the repository and note its complete location: `github.com/<owner>/<repository>`. You will use this as your lab repository throughout the exercises.
