# Create a composite action using PowerShell (pwsh)

Create the action in a new folder `hello-world-composite-pwsh-action` in [your lab repository](../).

1. Create [`hello-world-composite-pwsh-action/action.yml`](/../../new/main?filename=hello-world-composite-pwsh-action%2Faction.yml) and [`hello-world-composite-pwsh-action/goodbye.ps1`](/../../new/main?filename=hello-world-composite-pwsh-action%2Fgoodbye.ps1).

<details>
  <summary>Solution: action.yml</summary>

```YAML
name: Hello World (pwsh)
description: Greet someone and record the time
inputs:
  who-to-greet:
    description: Who to greet
    required: true
    default: World
outputs:
  time:
    description: The time we greeted you
    value: ${{ steps.time.outputs.time }}
runs:
  using: composite
  steps:
    - name: Set Greeting
      shell: pwsh
      run: Write-Host "Hello $env:INPUT_WHO_TO_GREET."
      env:
        INPUT_WHO_TO_GREET: ${{ inputs.who-to-greet }}

    - name: Get the time
      id: time
      shell: pwsh
      run: |
        "time=$(Get-Date -Format o)" | Out-File -FilePath $env:GITHUB_OUTPUT -Encoding utf8 -Append

    - name: Run goodbye.ps1
      shell: pwsh
      run: ./goodbye.ps1
      working-directory: ${{ github.action_path }}
```

</details>

<details>
  <summary>Solution: goodbye.ps1</summary>

```powershell
Write-Host "Goodbye"
# Workflow command: show an annotation in the run summary
Write-Host "::notice::Goodbye from PowerShell"
```

</details>

> **Note**
> `pwsh` is available on all GitHub hosted runners (Linux, Windows and macOS).
