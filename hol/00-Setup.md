# 🔨 Hands-on: Setting up your lab repository

All hands-on labs are done in one repository that you create once: your lab repository. The location of this repository differs per user, so the labs refer to it as "your lab repository" and use relative links.

Choose the guide for where you want to create the lab repository:

- [Create it on GitHub.com](00.1-create-on-public.md)
- [Create it on GitHub Enterprise Cloud (EMU)](00.2-create-on-ghec-emu.md)
- [Create it on GitHub Enterprise Cloud with data residency](00.3-create-on-ghe-com-emu.md)

Note the complete repository location (host, owner or organization, and repository name). You will continue all labs in the lab repository you've created.

## Summary

You now have your lab repository. Continue with [My first workflow](01-My-first-workflow.md).
