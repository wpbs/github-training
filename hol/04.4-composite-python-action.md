# Create a composite action using Python

Create the action in a new folder `hello-world-composite-python-action` in [your lab repository](../).

1. Create [`hello-world-composite-python-action/action.yml`](/../../new/main?filename=hello-world-composite-python-action%2Faction.yml). Python is pre-installed on GitHub hosted runners; [actions/setup-python](https://github.com/actions/setup-python) gives you control over the version. Use `shell: python` to run the script inline in the step, so no separate script file is needed.

<details>
  <summary>Solution: action.yml</summary>

```YAML
name: Hello World (python)
description: Greet someone and record the time
inputs:
  who-to-greet:
    description: Who to greet
    required: true
    default: World
outputs:
  time:
    description: The time we greeted you
    value: ${{ steps.greet.outputs.time }}
runs:
  using: composite
  steps:
    - name: Set up Python
      uses: actions/setup-python@v7.0.0
      with:
        python-version: '3.x'

    - name: Greet
      id: greet
      shell: python
      run: |
        import os
        from datetime import datetime, timezone

        who = os.environ["INPUT_WHO_TO_GREET"]
        print(f"Hello {who}.")

        # Workflow command: show an annotation in the run summary
        print(f"::notice::Greeted {who}")

        # Write outputs to the file in GITHUB_OUTPUT (not ::set-output)
        with open(os.environ["GITHUB_OUTPUT"], "a", encoding="utf-8") as output:
            output.write(f"time={datetime.now(timezone.utc).isoformat()}\n")
      env:
        INPUT_WHO_TO_GREET: ${{ inputs.who-to-greet }}
```

</details>

> **Note**
> With `shell: python` the content of `run` is saved to a temporary file and executed with `python`. Pass inputs through `env:` and read them with `os.environ`, just like in the other flavours.

## Extra: move the code to a separate Python file

Inline code is fine for a few lines, but it gets awkward quickly. Moving it to its own file has several advantages:

- **Easier to test locally:** run `python greet.py` on your machine (with `INPUT_WHO_TO_GREET` and `GITHUB_OUTPUT` set) without pushing to GitHub and waiting for a workflow run.
- **Unit tests:** a real module can be imported and tested with `pytest` or `unittest`; code embedded in YAML can't.
- **No YAML and quoting pitfalls:** no issues with indentation inside the `run: |` block, YAML special characters, or escaping quotes and `${{ }}` expressions.
- **Editor support:** syntax highlighting, linting, formatting (for example `ruff` or `black`), type checking and debugging only work on real `.py` files.
- **Reviewable and scannable:** diffs, code owners, and code scanning (CodeQL) treat it as regular Python code, and tools can find problems in it.
- **Structure and reuse:** you can split the code into functions and modules, import it from other scripts, and declare dependencies in a `requirements.txt`.
- **Safer by default:** the script reads inputs from environment variables, so no `${{ }}` expression ends up inside the code (see the script injection lab).

1. Create [`hello-world-composite-python-action/greet.py`](/../../new/main?filename=hello-world-composite-python-action%2Fgreet.py) and move the Python code from the `run` block of the `Greet` step into it.

<details>
  <summary>Solution: greet.py</summary>

```python
import os
from datetime import datetime, timezone

who = os.environ["INPUT_WHO_TO_GREET"]
print(f"Hello {who}.")

# Workflow command: show an annotation in the run summary
print(f"::notice::Greeted {who}")

# Write outputs to the file in GITHUB_OUTPUT (not ::set-output)
with open(os.environ["GITHUB_OUTPUT"], "a", encoding="utf-8") as output:
    output.write(f"time={datetime.now(timezone.utc).isoformat()}\n")
```

</details>

2. Change the `Greet` step in `action.yml` to run the file. Use `github.action_path` (the `GITHUB_ACTION_PATH` variable) to locate it, because the working directory of the step is the workspace of the caller, not the folder of the action.

<details>
  <summary>Solution: action.yml</summary>

```YAML
    - name: Greet
      id: greet
      shell: bash
      run: python "$GITHUB_ACTION_PATH/greet.py"
      env:
        INPUT_WHO_TO_GREET: ${{ inputs.who-to-greet }}
```

</details>
